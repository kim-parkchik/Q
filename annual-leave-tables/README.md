# 年次有給休暇の付与日数の元データ

## 出典・利用条件

このフォルダのファイルは、e-Gov 法令検索の法令 API（デジタル庁）から取得した条文データ（XML）です（2026年11月13日に取得）。
法令の条文は、著作権の対象になりません（著作権法13条1号）。

- `src/constants/annualLeave.ts` は、これらのファイルの文と表を、スクリプトで読み取って作成したものです（手で書き写していません）。
- Q は e-Gov・デジタル庁・厚生労働省が作成・保証するものではありません。

ファイル名は、Q で分かりやすいように付け直したものです。

| ファイル | 内容 | 入手元 | 使い方 | SHA-256 |
|---|---|---|---|---|
| rouki-39.xml | 労働基準法 39条（年次有給休暇） | https://laws.e-gov.go.jp/api/1/articles;lawId=322AC0000000049;article=39 | 1項（6か月・8割・10労働日）、2項の表（継続勤務年数ごとに足す日数）、7項（年5日の時季指定の義務がある人：10労働日以上） | `8070e1cdd067f5420b857d916cbee58da70ee7dd4e25ff25660f443c8c9892ca` |
| roukisoku-24-3.xml | 労働基準法施行規則 24条の3（比例付与） | https://laws.e-gov.go.jp/api/1/articles;lawId=322M40000100023;article=24_3 | 1項（30時間）・2項（5.2日）・3項の表（比例付与の日数）・4項（4日）・5項（216日） | `77956bfdf49590a75aa48197f67844963ab2cd29f1dc89a01be3d89a1479a626` |

## データの作り方

追加のインストールは要りません（Python の標準ライブラリだけで動きます）。

```
python3 -I scripts/import_annual_leave_tables.py \
    annual-leave-tables/rouki-39.xml \
    annual-leave-tables/roukisoku-24-3.xml \
    src/constants/annualLeave.ts
```

スクリプトは、条文の漢数字を数にして表を作り、比例付与の表の日数がすべて「通常の付与日数 × 週所定労働日数 ÷ 5.2（1日未満切り捨て）」と同じか確かめます（労働基準法39条3項）。
条文の文や表の形が変わっていたり、照らし合わせが合わなかったりしたら、ファイルを作らずに止まります。

法改正があったときは、上の入手元の URL から取り直して（ファイル名・出どころ・大きさを伝え、許しを得てから）、スクリプトを流し直してください。
