## データの作り方

PDF の文字は、macOS の PDFKit で取り出します（`scripts/pdf_to_text.swift`。追加のインストールは要りません）。

```
python3 -I scripts/import_commute_limits.py commute-tables src/constants/tax/commuteLimits.ts
```

- 距離の区分・金額・最高限度（15万円）・駐車場等の上限（5,000円）・適用が始まる日は、すべてファイルの文字から機械的に読み取ります（全角は半角にします）。
- 令和8年の表が Q&A とタックスアンサーで一つ残らず同じでなければ止まります。
- 令和7年の表は、令和7年11月の PDF の「改正後」と、Q&A の「改正前」の「同左」の行が同じでなければ止まります。
- 区分が 0km から切れ目なく並んでいない・2km未満が全額課税でない・金額が距離とともに増えていないときも止まります（中途半端なデータは作りません）。
- 作ったあとは `bun test` で、Q&A の計算例（ケースＡ〜Ｅ・Ｑ４－２）と同じになるか確かめます（`src/utils/commuteAllowance.test.ts`）。

## 改正があったとき

1. 国税庁の新しい資料（改正の案内・Q&A、タックスアンサー No.2585）を、このフォルダに置く
2. `scripts/import_commute_limits.py` に、新しい資料を読む部分と、照らし合わせを足す
3. 上のコマンドでデータを作り直し、`bun test` で確かめる

※ 数字を手やAIで書き写さないこと。
