# 雇用保険の届書（電子申請用ファイル）の元データ

Q の雇用保険の届書（資格取得届・資格喪失届（離職票交付なし）・資格喪失届（離職票交付あり。離職証明書）・転勤届・個人番号登録届）の
電子申請用ファイル（ハローワークに出す CSV形式届書ファイル。`10101-shutoku.csv`・`10191-soshitsu.csv`・`10191-rishoku.csv`・`10106-tenkin.csv`・
`10702-bango.csv`。`src/utils/koyoCsv.ts`・`src/utils/koyoReport.ts`）で使う形
（ファイル名・帳票種別・代表届書コード・連記式項目バージョン・各レコードの項目の名前と並びと種別・文字数・書ける元号・区分のコード、
国籍・地域一覧、在留資格一覧、使える1バイト文字・2バイト文字のコードの範囲）と、離職理由の区分の名前は、
厚生労働省の仕様書と手引きの PDF から、スクリプトで読み取って `src/constants/koyoTodoke.ts` に作っています（手で書き写していません）。

離職証明書の賃金の欄の書き方（`src/utils/wageCertificate.ts`）と、給付の申請に事業主が書く内容（`src/utils/koyoBenefits.ts`）は、
下の手引き（第２編・第３編）の説明と記入例によります（テストで記入例と同じになることを確かめています）。

## データの作り方

追加のインストールは要りません（Python の標準ライブラリと、macOS の PDFKit（`scripts/pdf_to_chars.swift`）だけで動きます）。

```
python3 -I scripts/import_koyo_format.py koyo-format/source/specs02.pdf koyo-format/source/001738607.pdf src/constants/koyoTodoke.ts
```

読むところ（仕様書）：表紙の版、3.1 (2) ＣＳＶ形式届書ファイルのファイル名、表3.3.1-1 電子申請用ファイルの構成要素（[kanri]・[data]・収録件数 1,000件以下）、
表3.4 使用可能文字一覧（1バイト文字）・使用可能コード範囲（2バイト文字。いちばん右の「使用可能コード範囲」の列を、字の位置で読む）、
4.1.1 ＦＤ管理レコード（代表届書コード・届書ごとの連記式項目バージョン）、4.1.3.1 事業所数情報、4.1.3.2 事業所情報、
4.1.5〜4.1.9 の5つの届書のデータレコードの項目構成（図）と項目説明（表）、参考資料３ 国籍・地域一覧、参考資料４ 在留資格一覧、
参考資料５ 被保険者氏名（ローマ字）使用可能文字種一覧。
手引き（第２編）：「離職理由欄（⑦欄）の各項目の内容について」の区分の名前（1(1)「倒産手続開始、手形取引停止による離職」など）。

このファイルは、どのレコードも1行目に項目の名前を並べた「項目行」を書くので、項目の名前は項目構成の図の字のまま（全角・半角も）にします
（図の名前の前後の空白だけは取ります。離職票交付ありの図に「, 被保険者期間算定対象期間開始（月）11」と空白が入っているため）。
項目説明の表は枠がつながっていて、字の並びでは列がわからないので、表の見出しの「項番」「種別」「文字数」の位置で列に分け、
項番と同じ高さの種別・文字数を結び付けます（「漢字」の下に離れて並ぶ「数字 英字 カナ」は、カナなどで書くときの決まり。
「漢字 数字 英字 カナ」が続けて並ぶ項目は、全角・半角どちらでも書ける項目）。区分のコード（“1” など）は、設定内容の「・新規 ：」と
同じ高さの “1” を結び付けて読みます（2行にわたるラベルは「：」で終わる行の高さ）。表の右の作成例の列の印（「ス」など）は除いて読みます。
資格喪失届（離職票交付あり）の賃金の欄（02〜25）は、表では「XX」として1回だけ書いてあるので、同じ決まりを24回くり返し、
図の名前が「02」を「03」〜「25」にしたものと同じことを確かめます。
在留資格の「特定技能 1号」の空白は PDF の字の間の空きなので取り（在留カードは「特定技能1号」）、CSV に書く値が在留資格の初めの20字と同じことを確かめます。

スクリプトは、次のときにファイルを作らずに止まります。

- 項目説明の表のどれかの項番の種別・文字数を読めない、文字数と種別が結び付かない
- 項目構成の図の項目の数と、表の項番がそろわない（離職票交付ありは 1〜108 と 454〜524。109〜453 は賃金の欄のくり返し）
- 仕様書の作成例の行（資格取得届・資格喪失届（離職票交付なし）・転勤届は作成例の図、離職票交付あり・個人番号登録届は項目構成の図の例の行）が、
  読んだ決まり（数字の項目は数字だけ・文字数）に合わない
- 連記式項目バージョンが、表の説明と図の例の行で違う。帳票種別がファイル名と合わない
- 喪失原因・性別などのコードが届書で違う。離職理由の選択（「選択しない」0・「選択する」1）が20個でない
- 国籍・地域一覧・在留資格一覧が作成例のコード（アメリカ合衆国 840・フランス 250・永住者 26・定住者 29 など）と合わない
- 手引きの離職理由の区分を読めない

仕様書の作成例のうち、資格喪失届（離職票交付なし）の行（図4.1.6-3）は離職票交付希望が「1」ですが、表4.1.6-1 は「“2”「無」を設定する
（離職票交付希望が有“1”は入力不可）」なので、Q は「2」を書きます（`src/utils/koyoReport.test.ts`）。
