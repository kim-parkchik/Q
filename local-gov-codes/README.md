# 全国地方公共団体コードの元データ

## 出典・利用条件

このフォルダの Excel ファイルは、総務省が公開している「都道府県コード及び市区町村コード」（全国地方公共団体コード）です。

- 出典：総務省ホームページ「全国地方公共団体コード」（https://www.soumu.go.jp/denshijiti/code.html）
- 総務省ホームページのコンテンツは、[公共データ利用規約（第1.0版）](https://www.soumu.go.jp/menu_kyotsuu/policy/tyosaku.html)に準拠した条件で利用できます（出典を記載すれば、複製・加工・再配布ができます）。
- `src/constants/localGovCodes.ts` は、この Excel を加工して作成したものです。
- これらのファイルは Q 本体のライセンス（AGPL-3.0）の対象ではありません。
- Q は総務省が作成・保証するものではありません。

|---|---|---|---|
| 都道府県コード及び市区町村コード_令和6年1月1日現在.xlsx | 令和6年1月1日現在の都道府県・市区町村（政令指定都市の区は別のシート） | https://www.soumu.go.jp/main_content/000925835.xlsx （2026年11月3日に取得） | `7d04c8a7f6a6e76a7823a0414a8422bf2b26bb6070766971df76eab58ea6ff78` |

## 使い道

給与支払報告書の「提出先市町村コード」（eLTAX の CSV の必須項目）に使います。
政令指定都市は、区ではなく市のコードを使います（地方税共同機構「給与支払報告書CSVレイアウト仕様書（総務省通知形式）」）。

## データの作り方

```
python3 -I scripts/import_local_gov_codes.py "local-gov-codes/都道府県コード及び市区町村コード_令和6年1月1日現在.xlsx" 2024-01-01 src/constants/localGovCodes.ts
```

- コードと名前は、すべて Excel の表から機械的に読み取ります。
- 都道府県が47そろわないとき、コードの6桁目の検査数字が合わないとき、都道府県とコードが合わないときは止まります。
- 市町村の合併などでコードが変わったら、総務省のページから新しい Excel を取ってきて、作り直してください。
