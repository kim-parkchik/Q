# 最低賃金の元データ

## 出典・利用条件

このフォルダの HTML ファイルは、厚生労働省の最低賃金制度のページを保存したものです（2026年10月31日に保存）。
厚生労働省ホームページのコンテンツは、[厚生労働省の利用規約](https://www.mhlw.go.jp/chosakuken/index.html)（公共データ利用規約 第1.0版に準拠）により、
出典を記載すれば複製・加工・再配布（商用を含む）ができます。

- 出典：厚生労働省ホームページ（下の表の各URL）
- `src/constants/minimumWage.ts` は、これらのページの表を加工して作成したものです。
- これらのファイルは Q 本体のライセンス（AGPL-3.0）ではなく、厚生労働省の利用規約に従います。
- Q は厚生労働省が作成・保証するものではありません。

| ファイル | 内容 | 入手元 |
|---|---|---|
| 地域別最低賃金_令和3-7年度.html | 地域別最低賃金の全国一覧（過去5年分） | https://saiteichingin.mhlw.go.jp/table/page_list_past.html |
| 地域別最低賃金_令和8年度.html | 地域別最低賃金全国一覧（令和8年度） | https://saiteichingin.mhlw.go.jp/table/page_list_nationallist.php |

※ 令和3年度より前（2021年10月ごろより前）の最低賃金は、このページの表に出ていないため、Q ではまだ比べられません。
（「過去5年分」のページの HTML には、画面に出ていない古い年度がコメントとして残っていますが、使っていません）

## 新しい年度を追加するとき

1. 厚生労働省のページを保存し直す（今年度のページは、新しい年度の金額と前年度の金額を両方表示している）
2. データファイルを作る（追加のインストールは要らない）

   ```
   python3 -I scripts/import_minimum_wage.py minimum-wage-tables/地域別最低賃金_令和4-8年度.html minimum-wage-tables/地域別最低賃金_令和9年度.html src/constants/minimumWage.ts
   ```

   ※ 過去5年分のページは毎年1年ずつずれるので、古い年度が消えないように、スクリプトで前の年のファイルも読むようにすること。
3. `bun test` で確認する

※ 数字を手やAIで書き写さないこと。スクリプトは、2つのページで同じ年度の金額・発効日が食い違うと止まります。
