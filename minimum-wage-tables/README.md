# 最低賃金の元データ

## 出典・利用条件

このフォルダのファイルは、厚生労働省が公開しているものです（HTML ファイルは2026年10月31日に保存、Excel ファイルは2026年11月7日に取得）。
厚生労働省ホームページのコンテンツは、[厚生労働省の利用規約](https://www.mhlw.go.jp/chosakuken/index.html)（公共データ利用規約 第1.0版に準拠）により、
出典を記載すれば複製・加工・再配布（商用を含む）ができます。

- 出典：厚生労働省ホームページ（下の表の各URL）
- `src/constants/minimumWage.ts` は、これらのファイルの表を加工して作成したものです。
- これらのファイルは Q 本体のライセンス（AGPL-3.0）ではなく、厚生労働省の利用規約に従います。
- Q は厚生労働省が作成・保証するものではありません。

ファイル名は、Q で分かりやすいように付け直したものです。

Q のデータには入れず、令和元年度の金額が続くものとして扱います。

## データの作り方

追加のインストールは要りません（Python の標準ライブラリだけで動きます）。

```
python3 -I scripts/import_minimum_wage.py minimum-wage-tables/地域別最低賃金改定状況_平成14-令和8年度.xlsx minimum-wage-tables/地域別最低賃金_令和3-7年度.html minimum-wage-tables/地域別最低賃金_令和8年度.html src/constants/minimumWage.ts
```

- 金額・発効日は、すべてファイルの表から機械的に読み取ります（Excel のふりがなは読みません）。
- 2つの HTML ページに出ている年度（画面に出ていない令和元年度・令和2年度も）は、Excel と一つ残らず同じでなければ止まります。
- 47都道府県がそろわないとき、Excel の年度が1年ずつ並んでいないとき、据え置きの年度ではないのに発効日・金額が前の年度より後・上でないときも止まります。
- 作ったあとは `bun test` で確かめます（`src/utils/minimumWage.test.ts`）。

## 新しい年度を追加するとき

1. 「地域別最低賃金の全国一覧」のページから、新しい年度までの改定状況の Excel を取り直す（ファイルの URL は年度ごとに変わる）。
   最低賃金制度のページ（過去5年分・今年度）も保存し直す（今年度のページは、新しい年度の金額と前年度の金額を両方表示している）
2. `scripts/import_minimum_wage.py` の `EXCEL_URL` を新しい URL にし、上のコマンドのファイル名を新しいものにしてデータを作り直す
3. `bun test` で確認し、この README の表（ファイル名・入手元・SHA-256）を直す

※ 数字を手やAIで書き写さないこと。
