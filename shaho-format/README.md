# 社会保険の届書（電子申請用ファイル）の元データ

Q の賞与支払届の電子申請用ファイル（CSV形式届書ファイル。年金事務所に出す `SHFD0006.CSV`。`src/utils/shahoCsv.ts`・`src/utils/bonusReport.ts`）で使う形
（ファイル名・識別符号・各レコードの項目の並びと種別・文字数、代表届書コード・様式コード、元号のコード、都道府県コード、使える1バイト文字・2バイト文字のコードの範囲）は、
厚生労働省・日本年金機構の仕様書の PDF から、スクリプトで読み取って `src/constants/shahoTodoke.ts` に作っています（手で書き写していません）。

## データの作り方

追加のインストールは要りません（Python の標準ライブラリと、macOS の PDFKit（`scripts/pdf_to_text.swift`）だけで動きます）。

```
python3 -I scripts/import_shaho_format.py shaho-format/source/specs081001_17.0.pdf src/constants/shahoTodoke.ts
```

読むところ：表紙の版、3.1.1 ファイル名、表3.3-1 ファイルの構成要素、表3.4-2 使用可能文字一覧（1バイト文字）、表3.4-3 使用可能コード範囲（2バイト文字）、
4.1.1 媒体管理レコード（年金事務所提出）、表4.3.1-1 事業所数情報、4.3.2.1 事業所情報（年金事務所提出）、
4.9.1 賞与支払届・70歳以上被用者賞与支払届データレコード（年金事務所提出）、参考資料3 都道府県コード一覧。

スクリプトは、次のときにファイルを作らずに止まります。

- 項目説明の表のどれかの項目を読めない（PDF の表の枠がつながっている項目は、字の並びが崩れるので、項目ごとに並びを決めて読んでいる）
- 項目構成の図の項目の名前・並びと、読んだ項目説明の並びが合わない
- 都道府県コードが47でない・重なっている
- 1バイト文字の一覧の数字・英大文字・英小文字・半角カナの数が 10・26・26・58 でない
- 2バイト文字の使用可能コード範囲や、使えないコードの注を読めない

## 気をつけること

- 都道府県コードは、全国地方公共団体コード（東京都は 13）ではなく、年金機構の一覧（東京都は 21、神奈川県は 31、大阪府は 41、愛知県は 51）です。
- 2バイト文字は、仕様書の使用可能コード範囲のコードをシフトJISとして読んで、使える字の表を作ります（`src/utils/shahoCsv.ts`）。
  JIS の書き方の字（〜・−・— など）は、シフトJISで読んだときの字（～・－・― など）と同じコードにします。
- 健康保険組合・厚生年金基金に出すファイル（KPFD0006.CSV・KNFD0006.CSV）や、算定基礎届・月額変更届などのデータレコードは、まだ作っていません。
