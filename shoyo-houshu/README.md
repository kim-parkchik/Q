# 年4回以上払う賞与（社会保険の「賞与に係る報酬」）の元データ

同じ性質の賞与を年4回以上払うと、健康保険・厚生年金保険では「賞与」ではなく「報酬」になり、7月1日前の1年間に受けた額の12分の1を
毎月の報酬に足して標準報酬月額を決めます（賞与支払届は出さず、賞与からは保険料を引きません）。
Q の決まりは `src/utils/shoyoHoushu.ts`、数（4回・12・7月1日・7〜9月）は `src/constants/shoyoHoushu.ts` です。

- 1(1)：毎年7月1日現在で、賞与の支給が、諸規定で年間を通じ4回以上と客観的に決まっているか、7月1日前の1年間に4回以上行われていれば、報酬。
  7月2日以降に回数が変わっても、次の定時決定（7・8・9月の随時改定を含む）の標準報酬月額を使うまでは前の扱いのまま
- 1(2)：名前が違っても同じ性質のものごとに数える。例外的に分けて払ったものはまとめて1回。その年だけ払ったことが明らかなものは数えない
- 2(1)：定時決定と7・8・9月の随時改定のときに、7月1日前の1年間に受けた賞与の額を12で割る（諸規定が変わって報酬になったときは、変わった後の諸規定で受けたであろう額を12で割る）
- 2(2)：資格取得時は、同様の業務に従事し同様の賞与を受ける人の、賞与に係る報酬の平均額
- 2(3)：賞与に係る報酬の額が変わっただけでは随時改定しない。7・8・9月以外の随時改定は、計算し直さずに前の額を足す

`src/constants/shoyoHoushu.ts` は、この HTML から次のスクリプトで作ります（手で書き写さない。言い回しが見つからない・同じ数がところによって違うときは止まります）。

```
python3 -I scripts/import_shoyo_houshu.py shoyo-houshu src/constants/shoyoHoushu.ts
```

- ガイドブック 16ページ（PDF の19ページ）のケース⑦「賞与などが年4回以上支給されたとき」：前年7月からその年の6月までに4回以上の賞与が支払われたら、
  合計額を12で割った額を各月の報酬に加える。例は 9月 120,000円・12月 380,000円・3月 150,000円・6月 250,000円 ＝ 900,000円 ÷ 12 ＝ 75,000円を、
  4〜6月の 270,000円に足して 345,000円（総計 1,035,000円・平均額 345,000円）。記入例は、⑪通貨に「1月あたりの賞与を加えた合計」、
  ⑱備考の「9.その他」に「賞与 9.12.3.6月 75,000円」（`src/utils/shoyoHoushu.test.ts` の期待値）。
  ページの字は絵なので、macOS の文字認識（`scripts/pdf_ocr.swift`）と画像で読みました
- ガイドブック 27ページ「5.賞与支払届」：標準賞与額の対象は年3回以下の支払いのもので、年4回以上支払うものは標準報酬月額の対象
- ガイドブック 36ページ Q24：過去3回分を賞与支払届で届け出て保険料を払っていても、諸規定で年4回以上と決めていれば、7月1日前の1年間に受けた4回以上の賞与の合計を12で割って
  各月の報酬に入れる（その年に限り払ったことが明らかなら回数に入れず、賞与支払届で届け出る）
- Q&A Q2〜Q4・Q7・Q8：同じ性質かは名前ではなく諸規定・賃金台帳で分けられるかで決める。諸規定を新しく作ったときは、年4回以上と決めていても、
  次の定時決定の標準報酬月額を使うまでは「賞与」（賞与支払届を出す）。そのあとは支給実績から、諸規定の回数であったとすれば7月1日前の1年間に受けたであろう額を12で割る。
  支給間隔によらず、年3回以下なら賞与。「支給することができる」の規定は、客観的に定められているとは言えない
- 事例集：年4回以上の賞与の扱いは書かれていない（報酬・賞与の範囲の問1だけ）
