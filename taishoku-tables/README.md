# 退職手当等（退職金）の税額の元データ

Q の退職金の計算（退職所得控除額・課税退職所得金額・源泉徴収する所得税・特別徴収する住民税。`src/utils/retirementIncome.ts`）で使う数値は、
法令の条文（e-Gov 法令API の XML）と国税庁の PDF から、スクリプトで読み取って `src/constants/taishoku.ts` に作っています（手で書き写していません）。

計算のしかた（勤続年数の1年未満の切り上げ・課税退職所得金額の1,000円未満の切り捨て・住民税の100円未満の切り捨て・
申告書がないときの住民税・他の退職手当等があるとき）は、国税庁 タックスアンサー No.2732「退職手当等に対する源泉徴収」
（令和8年4月1日現在法令等）と、地方税法 第20条の4の2・第50条の6・第328条〜第328条の6 によります
（タックスアンサーの例・手引の見本の額と同じになることを `src/utils/retirementIncome.test.ts` で確かめています）。

法令の条文（XML）はリポジトリに入れています（法令は著作権の対象になりません。著作権法13条）。
**国税庁の PDF はリポジトリには入れていません**（`source/` は .gitignore）。
作り直すときは、上の入手元から取ってきて `source/` に置き、SHA-256 を確かめてください（違えば、資料が変わったので、読んでから作り直します）。

## データの作り方

追加のインストールは要りません（Python の標準ライブラリと、macOS の PDFKit だけで動きます）。

```
python3 -I scripts/import_taishoku_tables.py taishoku-tables src/constants/taishoku.ts
```

・所得税法 第30条から、退職所得の金額（2分の1、短期退職手当等の300万円・150万円、特定役員退職手当等は2分の1にしないこと）、
退職所得控除額（40万円・20年・800万円・70万円・80万円・障害者の100万円）、短期退職手当等と特定役員退職手当等の「5年以下」を、
条文の決まった言い回し（「四十万円に当該勤続年数を乗じて計算した金額」など）から漢数字で読みます。
・所得税法施行令 第69条2項の「一年未満の端数を生じたときは、これを一年として」を確かめます。
・地方税法 第50条の4・第328条の3 から、住民税の税率（百分の四・百分の六）を読みます。
・速算表の PDF（令和8年分・令和9年分）から、行ごとの境目・税率・控除額と「×102.1％」を読みます。
・手引 第3章から、「退職所得の受給に関する申告書」の提出がないときの「100 分の 20.42」を読みます。

スクリプトは、次のときにファイルを作らずに止まります。

- 条文の言い回しが見つからない、800万円が 40万円 × 20年 と違う、150万円が 300万円の2分の1 と違う、
  第30条2項1号と2号・3項1号と2号の年数や金額が食い違う、6項2号と3号の最低の額（80万円）が違う
- 速算表の見出し・行を読めない、行の境目がつながらない、税率・控除額が「税額の算式」の欄と違う、
  控除額が速算表の作り（前の行の控除額 ＋ 境目の金額 × 税率の差）と合わない、「1 円未満の端数があるときは、これを切り捨てます」がない
- 20.42 が、速算表の 102.1％ を整数の税率（20％）にかけた率でない

速算表は年分ごとにあります（令和8年分と令和9年分は同じ額で、令和9年分からは防衛特別所得税を含みます）。
次の年分の速算表が出たら、取ってきて `source/` に置き、スクリプトの読む PDF に足して作り直します。
