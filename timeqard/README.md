# TimeQard（タイムカード）

TimeQard は、給与ソフト Q の仲間の、**打刻だけをするソフト**です。事務所の入口などに置いたパソコン1台で、従業員が出勤・退勤などを押します。押した記録は CSV にして、Q の勤怠に取り込みます。

- インターネットにつながなくても動きます。記録はそのパソコンの中だけに残り、どこにも送りません。
- 使う設定にすると、同じネットワーク（社内の LAN・Wi-Fi）の中の各自のパソコンのブラウザからも押せます（6。インターネットからはつながりません）。
- 打刻用のパソコンには、給与やマイナンバーは入りません（入るのは、スタッフID・名前・入社日・退職日・カードの確かめ用の値だけ）。
- 設計の考え方は [DESIGN.md](DESIGN.md) にあります。

## 1. 入れ方

[ダウンロードのページ](https://github.com/kim-parkchik/Q/releases?q=TimeQard&expanded=true)から、入口のパソコンに合うものを選びます。Q の「TimeQard（打刻）」の画面の「ダウンロードのページを開く」からも開けます。打刻用のパソコンがインターネットにつながっていなければ、ほかのパソコンでダウンロードして、USB メモリで運びます。

TimeQard には、まだ「署名」（作った人を OS に証明するしくみ。費用がかかる）をしていません。そのため、Windows と Mac では、初めて入れるときに警告が出ます。下の手順で進めてください。

### Windows 10・11

1. 「TimeQard_（版）_x64-setup.exe」を開きます。
2. 「Windows によって PC が保護されました」と出たら、「詳細情報」を押し、「実行」を押します。
3. あとは画面のとおりに進めます。
4. 入れるときに「WebView2」がないと言われたら、インターネットにつないでから、もう一度入れてください（Windows 10 の多くと Windows 11 には、初めから入っています）。

Windows 7・8.1 では動きません。Windows 11 にできない古いパソコンは、Ubuntu を入れて使えます。

### Mac（macOS 10.15 Catalina 以上）

1. 「TimeQard_（版）_universal.dmg」を開き、TimeQard を「アプリケーション」フォルダに入れます。
2. TimeQard を開きます。「開けません」「確かめられません」と出たら、「完了」（または「キャンセル」）を押します。
3. 「システム設定」→「プライバシーとセキュリティ」を開き（古い Mac では「システム環境設定」→「セキュリティとプライバシー」→「一般」）、下のほうの「TimeQard は…」の横の「このまま開く」を押します。
4. もう一度 TimeQard を開いて「開く」を押します。2回目からは、そのまま開きます。

### Ubuntu（22.04 以上）

- 「TimeQard_（版）_amd64.deb」を開くと、「ソフトウェアのインストール」で入れられます。または、端末で次のように入れます。

  ```bash
  sudo apt install ./TimeQard_0.1.0_amd64.deb
  ```

- 「TimeQard_（版）_amd64.AppImage」なら、入れずに使えます。ファイルを右クリックして「プロパティ」→「実行可能」に印を付けてから開きます（Ubuntu 22.04 以上で開かないときは、`sudo apt install libfuse2` が要ります）。
- メモリの少ないパソコンなら、軽い Ubuntu の仲間（Lubuntu など）でも動きます。

## 2. 使うもの

- **打刻カード**：Q の「TimeQard（打刻）」の画面で作って印刷します（名刺の大きさ。A4 の名刺用紙に10枚）。
- **USB の QR コード読み取り機**：キーボードのように文字を打ち込むもの（「USB-HID」「キーボード」として動くと書いてあるもの）。読み取ったあとに Enter を送る設定にします（多くは初めからそうなっています）。日本語入力がオンのままでも読めます。
- カードがない日は、画面の「ID で押す」から、スタッフID を入れて押せます（Q に取り込むときに「カードなし」として一覧に出ます）。
- **パソコンのカメラ**（ノートパソコンに付いているもの・USB でつなぐカメラ）にカードを向けても読めます。
  - 初めて使うときに「カメラを使ってよいか」と聞かれたら、「許可」を押します。映像は保存せず、どこにも送りません。
  - 暗い場所や、ピントの合わない古いカメラでは読みにくいことがあります。確実に読みたいときは、USB の読み取り機を使ってください。
  - カメラを使わないときは、「管理」→「設定」→「カメラ」で切れます。カメラが2つ以上あれば、使うカメラも選べます。

## 3. 最初の設定

1. TimeQard を開くと、「最初の設定」が出ます。
2. **管理のパスワード**を決めます。管理の画面を開くときと、TimeQard を閉じるときに使います。
3. Q の「TimeQard（打刻）」の画面で「従業員ファイルを書き出す」を押し、できたファイル（「○○株式会社_TimeQard従業員_2026-11-07.json」）を USB メモリで運んで、**従業員ファイル**として選びます。読み込んだら、USB メモリのファイルは消してください（名前が入っているため）。
4. 「管理」→「設定」で、次を決めます。
   - 休憩のボタンを出すか（初めは出す）。休憩は1日に何回でも押せます。私用の外出・中抜けも休憩として押します（仕事での外出は働いた時間なので押しません）。
     休憩のボタンを出さない会社は、Q の会社設定の給与規定グループで「決まった休憩」を決めると、勤怠を確定するときにその休憩を引いて計算します
   - 画面いっぱいに出すか、パソコンを点けたら TimeQard を開くか
   - **毎日の控えのフォルダ**（USB メモリなど、このパソコンとは別の場所）

## 4. 毎日の使い方

1. カードを読み取り機にかざします（または「ID で押す」を押します）。
2. 名前と、いまの状態（出勤前・出勤中など）が出ます。大きいボタン（出勤前なら「出勤」）を押します。ほかのボタンは「そのほか」から押せます。
3. 「山田 太郎さん　出勤 8:58 を記録しました」と出たら終わりです。押し間違えたら、**1分のあいだ**は「取り消す」を押せます。
4. 押し忘れ・押し間違いは、カードをかざして（または ID で）から「**押し忘れを申し出る**」で、日・種類・時刻・理由を入れます。担当者が確かめてから、Q で直します。
   押し忘れた休憩や、私用で抜けた時間（中抜け）は、種類で「**休憩（中抜けも）**」を選び、始めと終わりの時刻を入れます。休憩を取れなかった日は、種類で「**休憩を取れなかった**」を選びます（時刻はいりません）。

TimeQard を閉じるときは、閉じるボタンを押して管理のパスワードを入れるか、「管理」→「TimeQard を閉じる」を押します。

## 5. 締めのあと（Q に取り込む）

1. TimeQard の「管理」→「CSV の書き出し」で、期間（先月・今月・日付で選ぶ）を選んで「CSV を書き出す」を押し、USB メモリに保存します。ブラウザ版を使っていれば、Q のパソコンのブラウザで「管理者の方」から入って、CSV をダウンロードすることもできます（6）。
2. Q の「TimeQard（打刻）」の画面（または勤怠の「CSV 取り込み」）で、その CSV を選びます。
3. 取り込む前に、まとめ（入れる日数・Q にない ID・カードなしで押した打刻・ブラウザで押した打刻・注意・押し忘れの申し出）が出ます。確かめてから「取り込む」を押します。申し出は、確かめたものだけ選んで、修正の欄に入れます（「休憩を取れなかった」を選ぶと、その日を「休憩なし」にします）。
4. Q の勤怠の画面で確かめて直し、確定します。

同じ期間を何度書き出して取り込んでも大丈夫です（確定した日は上書きしません）。

## 6. ブラウザ版（各自のパソコンのブラウザから押す）

入口のパソコンの TimeQard がサーバーになり、同じネットワーク（社内の LAN・Wi-Fi）の中のパソコンのブラウザから、スタッフID とパスワードでログインして押せます。インターネットからはつながりません。入口のパソコンで押すのも、いままでどおり使えます。

- **ブラウザでできること**：出勤・退勤・休憩（「管理」→「設定」で出すことにしたボタン。休憩は何回でも）、押した直後（1分以内）の取り消し、押し忘れの申し出（休憩・中抜け、「休憩を取れなかった」も）、自分の打刻と申し出の一覧、パスワードの変更。
- 時刻は、各自のパソコンの時計ではなく、**入口のパソコンの時計**で記録します。

**始め方（担当者）**

1. 入口のパソコンの「管理」→「ブラウザ版」で、「各自のパソコンのブラウザから押せるようにする」に印を付けます。パソコンに「ネットワークへの接続を許可するか」と聞かれたら、許可します（社内のネットワークだけで足ります）。
2. 出てきたアドレス（例：`https://192.168.0.10:8443/`）を、各自に伝えます。入口のパソコンのアドレスが変わらないように、ルーターの設定で固定してください。
3. **会社専用の証明書**を、各自のパソコンに1回だけ入れます（ブラウザとのやりとりを暗号にするためのもので、TimeQard がこの会社のためだけに作ります。社内のアドレスのページにしか使えません）。
   - 「証明書をファイルに保存する」で USB メモリに保存して運ぶか、各自のパソコンのブラウザで上のアドレスを開き、「このパソコンに、会社専用の証明書を入れる」からダウンロードします（入れる前の1回だけ、ブラウザが注意の画面を出します）。
   - 入れ方は、そのページに、Windows・Mac・Firefox・Ubuntu ごとに書いてあります。入れるときは、管理の画面に出ている「指紋」と同じかを見比べてください。
4. 「従業員のパスワード」で、人ごとに「はじめのパスワードを作る」を押し、出てきた紙を印刷して本人に渡します。期限は7日です。TimeQard にはパスワードを残さないので、紙の画面を閉じると二度と出せません（そのときは作り直します）。

**使い方（各自）**

1. ブラウザでアドレスを開き、スタッフID とパスワードでログインします。
2. 初めてのときは、自分だけのパスワード（8文字以上）に変えます。変えるまでは押せません。スタッフID と同じもの・同じ文字ばかり・「12345678」のような並びは使えません。
3. 大きいボタン（出勤前なら「出勤」）を押すと記録して、ログアウトになります。1分のあいだは「取り消す」を押せます。
4. ログインしたままにはなりません。何もしなくても、5分たつとログアウトになります。

**決まり**

- パスワードを5回続けてまちがえると、15分は使えません。忘れたときは、担当者が、はじめのパスワードを作り直します。
- 担当者は、ブラウザの「管理者の方」から管理のパスワードで入り、CSV のダウンロード・はじめのパスワードを作る・消すこともできます（5回続けてまちがえると、15分はブラウザからは入れません）。
- ブラウザで押した打刻には、つないできたパソコンのアドレスが残ります（「管理」→「打刻の一覧」）。ログインの記録は「管理」→「ブラウザ版」に出ます。
- 入口のパソコンの TimeQard を閉じているあいだは、ブラウザからも押せません。押せなかった分は、押し忘れの申し出で直します。
- 来客用の Wi-Fi など、つないだ機器どうしが見えない設定のネットワークからは、つながりません。
- いまは、パソコンのブラウザで使う形です（スマホは、証明書の入れ方が難しいので、あとで考えます）。

## 7. 控えと、パソコンが壊れたとき

- 「管理」→「設定」で控えのフォルダを決めておくと、1日に1回、記録のファイルの写し（「TimeQard_控え_2026-11-07_083000.db」）を作ります。新しいものから30個を残します。
- 記録のファイル（timeqard.db）の場所は、「管理」→「設定」に出ています。

| パソコン | 記録のファイルの場所 |
|---|---|
| Windows | `C:\Users\（名前）\AppData\Roaming\jp.payroll.timeqard\` |
| Mac | `（ホーム）/ライブラリ/Application Support/jp.payroll.timeqard/` |
| Ubuntu | `~/.config/jp.payroll.timeqard/` |

**控えから戻すとき**（新しいパソコンに入れ直したときなど）

1. TimeQard を入れます。開いていたら、管理の画面から閉じます。
2. 上の場所に、いちばん新しい控えを「timeqard.db」という名前で置きます。前からある `timeqard.db`・`timeqard.db-wal`・`timeqard.db-shm` があれば、別の名前にしてとっておきます。
3. TimeQard を開くと、控えを作ったときの打刻・設定・管理のパスワード・ブラウザ版の従業員のパスワードが入っています。会社専用の証明書は控えに入らないので、ブラウザ版を使っていたときは、新しい証明書を各自のパソコンに入れ直します（「管理」→「ブラウザ版」）。
4. 控えを作った時刻よりあとの打刻は入っていません。その分は、押し忘れの申し出か、Q で直します。

## 8. 困ったとき

| 出ていること | すること |
|---|---|
| 「パソコンの時計がおかしいので、押せません」 | パソコンの日付と時刻を直します（古いパソコンは、時計の電池が切れていて、電源を抜くと時計が戻ることがあります）。 |
| 「この会社のカードではありません」 | ほかの会社（ほかの会社ファイル）のカードです。 |
| 「このカードは使えません」 | 作り直す前の古いカードか、新しい従業員ファイルをまだ読み込んでいません。担当者が、Q で書き出した新しい従業員ファイルを読み込みます。 |
| 「入社日より前なので、押せません」 | 入社日を Q で確かめ、従業員ファイルを書き出し直して読み込みます。 |
| 「カメラを使うことが許されていません」 | Windows：「設定」→「プライバシーとセキュリティ」→「カメラ」で、アプリにカメラを許します。Mac：「システム設定」→「プライバシーとセキュリティ」→「カメラ」で、TimeQard をオンにします。 |
| Ubuntu でカメラが映らない | 端末で `sudo apt install gstreamer1.0-plugins-good` を入れてから、TimeQard を開き直します。 |
| 管理のパスワードを忘れた | パスワードを聞く画面の「パスワードを忘れたとき」から、Q で書き出した、いま読み込んでいるものより新しい従業員ファイルを選ぶと、決め直せます。 |
| ブラウザで「この接続ではプライバシーが保護されません」などの注意が出る | 会社専用の証明書を、そのパソコンにまだ入れていません（6 の 3）。入れたのに出るときは、開いたアドレスが、入口のパソコンの「管理」→「ブラウザ版」に出ているアドレスと同じかを確かめます。 |
| ブラウザでつながらない | 入口のパソコンの TimeQard が開いているか、「管理」→「ブラウザ版」で動いているか、同じネットワークにつないでいるかを確かめます。入口のパソコンのファイアウォールで、TimeQard を許可しているかも確かめます。 |
| 「ブラウザ版を始められませんでした」（入口のパソコン） | ほかのソフトが同じポートを使っているかもしれません。「管理」→「ブラウザ版」で、ポートを変えます（例：8444）。変えたら、新しいアドレスを各自に伝えます。 |
| 「パスワードを5回続けてまちがえたので、…使えません」 | 15分待つか、担当者に、はじめのパスワードを作り直してもらいます。 |
| 「前の形の TimeQard の記録です」 | TimeQard 0.1.0 で作った記録のファイルです（まだ作成中のため、前の形は読めません）。記録のファイル（timeqard.db）を別の場所に移してから開き直し、最初の設定からやり直します。 |

## 作る人へ

Q と同じリポジトリにあり、Q のために入っている部品（React・Vite・Tauri）を使います。CSV と従業員ファイルの形は `shared/timeqard/`（Q と TimeQard の両方が使う）で決めています。

```bash
bun run timeqard:tauri dev
```

```bash
bun test shared timeqard src/utils/attendanceImport.test.ts src/features/timeqard
```

```bash
cd timeqard/src-tauri && cargo test --offline
```

- 画面だけを作る：`bun run timeqard:build`（`timeqard/dist` にできる）
- Q の勤怠の「休憩の一覧」の画面だけを確かめる：同じく `/dev/breaks.html` を開く（見本の打刻の休憩を直して、働いた時間を下に出す）
- Q の会社独自の休暇（夏季休暇などの特別休暇）の画面を確かめる：同じく `/dev/leave.html` を開く（会社設定の「休暇の種類」・有給休暇管理の付与の知らせと残り・勤怠の区分。会社ファイルの代わりにページの中の表を使い、確定した日で計算した給与を下に出す）
- Q のフレックスタイム制の清算を確かめる：同じく `/dev/flex.html` を開く（2026年6月・月給30万円の人で、時間外・法定内・足りない時間（引く・繰り越す）・時給制の見本を並べ、勤怠の画面の知らせと給与の計算の結果を出す）
- Q の会社設定の「社会保険規定」（健康保険組合・国民健康保険組合）を確かめる：同じく `/dev/insurer.html` を開く（組合の料率を「何年何月分から」と一緒に足す・直す・消すと、下の見本の3人（協会けんぽ・健康保険組合・国保組合）の2026年6月分の社会保険料が変わる。6月分の料率がないと「確定できない」になる）
- Q の振込データ（全銀協規定形式）を確かめる：同じく `/dev/furikomi.html` を開く（会社設定の「振込元口座」と「振込データ」の画面。見本の4人（口座1つ・固定額と残り・口座なし（現金）・名義に漢字）の2026年11月支給の給与と冬季賞与で、「中身を見る」でファイルの中身（1レコード120バイト）を出す）
