# 郵便番号から住所（日本郵便の郵便番号データ）

Q の「住所検索」（従業員・会社・支店の画面）は、日本郵便の郵便番号データを Q の中に入れて引きます。郵便番号を外のサイトに送りません。
従業員の画面では、住所のフリガナ（都道府県・市区町村・町域の読み）も入れます。引くところは `src/utils/zipcode.ts`、データは
[public/zipcode/](../public/zipcode/)（郵便番号の1けためごとの `zip0.tsv` 〜 `zip9.tsv`）です。

- 日本郵便の「郵便番号データ（1レコード1行、UTF-8形式）の説明」に、郵便番号データに限っては著作権を主張せず、自由に配布してよいと書かれています。
  Q 用の形にしたもの（`public/zipcode/`）だけをリポジトリに入れ、出典を各ファイルの頭に書いています。
- このデータには、町域ごとの郵便番号だけが入っています。大口事業所などの個別の郵便番号（事業所の個別郵便番号）は入っていないので、引けません。

## Q 用の形にする

```
python3 -I scripts/import_zipcode.py zipcode/source/utf_ken_all.zip public/zipcode
```

1行の15の項目のうち、全国地方公共団体コード・郵便番号・都道府県・市区町村・町域とそれぞれのカナを使います。町域は、住所に書く形にします
（日本郵便の説明の書き方による）。

- 「以下に掲載がない場合」は町域なし（市区町村まで）
- 「○○の次に番地がくる場合」は、○○が市区町村なら町域なし。ほかの名前なら、その名前（西海市の「大島町の次に番地がくる場合」は「大島町」）
- 「○○一円」は、○○が市区町村なら町域なし（利島村一円など）。多賀町の「一円」は町域の名前なので、そのまま
- かっこ書き（「大通西（１〜１９丁目）」の丁目・番地の範囲、「（次のビルを除く）」、ビルの「（１階）」、小字の並びなど）は除く
- 「、」で並べた町域（「甲、乙」）と、岩手県の地割の範囲（「越中畑６４地割〜越中畑６６地割」「種市第１５地割〜第２１地割」）は、1つずつの町域に分ける
- 同じ郵便番号で、市区町村・町域・カナが同じになったものは1つにする（町域がいくつも残る郵便番号は、Q で選ぶ窓を出す）

同じ全国地方公共団体コードで名前やカナが違う行がある、かっこの後ろに字がある、カナにカタカナ・数字・英字のほかの字が残る、
思っていない書き方（「〜」「、」など）があるときは、作らずに止まります。2026年10月30日更新のデータでは、郵便番号 120,721、
町域がいくつもある郵便番号 1,297、市区町村 1,892 でした。

## 新しいデータにするとき

日本郵便は、毎月末ごろにデータを更新しています。

1. 上の入手元から utf_ken_all.zip を `zipcode/source/` に取ってくる
2. 上のスクリプトを流して `public/zipcode/` を作り直す（止まったら、新しい書き方が出てきたので、スクリプトを直す）
3. `bun test src/utils/zipcode.test.ts` を流す
4. この README の取得日・更新日・大きさ・SHA-256・件数を書き直す
